How to Play

The Name Chain Game!

  • A starting name is shown. You must enter a name where the first letter of the first name matches the first letter of the previous name's last name.
  • Example: If the last name was "Michael Jordan", you need someone whose first name starts with J (like "James Harden").
  • You and the computer take turns. Correct answers earn points!
  • Names cannot be reused once played.

Features

  • Streak Bonus: 3+ correct = 2x, 5+ = 3x, 7+ = 4x points!
  • Hints: Get progressive hints (initials first, then full name).
  • Power-Ups: Skip a turn, add time, or reveal valid answers.
  • Autocomplete: Start typing to see matching names.

Game Modes

  • Classic: Standard turn-based play. End when you want.
  • Timed: Beat the clock on every turn.
  • Survival: 3 lives. Wrong answer or timeout = lose a life.

Keyboard Shortcuts

  • Enter: Submit your answer
  • H: Use a hint (when not typing)
